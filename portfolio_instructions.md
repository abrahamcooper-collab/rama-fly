# Portfolio & Projects Implementation Instructions

## Overview
This document contains the guidelines and requirements for refactoring exterior services, creating the new Portfolio page, and showcasing project progress phases.

---

## 1. Exterior Work Removal
- Remove the entire **Exterior Work** section/pages and all of its associated services across the application.

---

## 2. Portfolio Page Creation
- Create a new dedicated **Portfolio** page (e.g., `/portfolio`).
- Build out the complete page structure, layout, styling, and navigation integration.

---

## 3. Dedicated "Projects" Section
- Inside the Portfolio page, create a prominent, dedicated section named **"Projects"**.
- This section will showcase the company's completed and ongoing projects.
- Source imagery from `/app/projects`.

---

## 4. Address Formatting & Folder Mapping
- Each folder name inside `/app/projects` corresponds to a project address (e.g., `Pictures -10 Plaza Street East Apt - 4G`).
- Display the address in the Projects section **excluding the house number** while keeping the rest of the address (e.g., *Plaza Street East Apt - 4G*).

---

## 5. Project Phases & Showcase Workflow
Each project directory contains subfolders organized by construction phase. Show pictures as provided, organized under their respective phase tags/tabs/galleries:

1. **Before photos**
2. **Demolition**
3. **Framing**
4. **Plumbing**
5. **Electrical**
6. **Insulation**
7. **Sheetrock**
8. **Plaster**
9. **Painting**
10. **Waterproofing**
11. **Tile installation**
12. **Wood flooring**
13. **Kitchen installation**
14. **Finish work**
15. **Final completed photos**

---

## Summary
The Portfolio page will feature a dedicated Projects section showcasing complete project lifecycles from initial state ("Before") through every phase of construction to the "Final completed photos".
